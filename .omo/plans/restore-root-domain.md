# 恢复根域名对博客前台的访问

## 目标
让根域名 `yulabu.cn`（裸域）和 `www.yulabu.cn` 都能正常打开博客前台，并保持现有部署稳定。

## 已知前提
- 之前问题：`www.yulabu.cn` 解析到 `206.237.13.114` 可访问。
- 根域（裸域）`yulabu.cn` 当前状态未知，可能没有同 IP 解析，或未走相同 Nginx 站点。

## 方案要点
1. **先做只读检查**（不改配置）：
   - 确认生产环境 Nginx `server_name` 包含 `yulabu.cn`。
   - 确认域名当前 DNS 解析现状（有无 A 记录、指向是否正确）。
2. **DNS 建议**（仅给你填写说明，不改任何本地代码）：
   - 在域名控制台新增/修改根域 `yulabu.cn` 的 **A 记录**，记录值填写：`206.237.13.114`。
   - 同时确认 `www` 的 A 记录也是 `206.237.13.114`（保持一致）。
3. **HTTPS 检查**：
   - 恢复访问后验证证书覆盖范围是否包含 `yulabu.cn`（Let's Encrypt 通常支持根域+www，但需确认）。
   - 如证书不包含根域，需要扩展证书 SAN（这一步会涉及服务器端运维操作，届时再按你指示处理）。

## 验证方式
- DNS 生效后访问：
  - `https://yulabu.cn` 应返回博客首页。
  - `https://www.yulabu.cn` 仍然正常。
- 命令行验证（你可在本地或跳板机执行）：
  - `dig +short yulabu.cn`
  - `dig +short www.yulabu.cn`
  - `curl -I https://yulabu.cn`

## 风险与注意事项
- DNS 传播可能需要几分钟到几小时。
- 修改根域解析可能影响其他服务（邮件、子域等），但本项目当前主要就是博客前台。
- 我们不会在这一步改动仓库代码或服务器配置，除非你明确授权。
