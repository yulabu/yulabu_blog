# Yulabu Blog

个人博客全栈项目。

- **前端**：Vue 3 + Vite + TypeScript，详见 [frontend/README.md](frontend/README.md)
- **后端**：Express 5 + Sequelize 6 + MySQL，详见 [server/README.md](server/README.md)

## 一键启动

根目录已配置 `concurrently`，可同时启动前后端：

```bash
npm install
npm run dev
```

默认访问地址：

- 前端：`http://localhost:5173`
- 后端：`http://localhost:3000`
