# Q6 修复：HomeHero 首帧"波浪先出现再迅速收起"

## 根因（实测）

dev 模式下 `HomeHero.vue` 的 scoped 样式不进 SSR HTML（vite 经 JS 注入、晚于首帧），而 dev SSR HTML 内联的是该组件**未编译的样式原文**——`html[data-hero-collapsed]` 六条折叠镜像规则里的 `:global()` 是非法 CSS，浏览器整条丢弃 → **首帧按展开态渲染**（波浪出现在全屏位置）；编译后的样式经 JS 到达后瞬间收到 360px，即你看到的"波浪先出现、迅速往下收"。

生产构建不受影响（产物是编译后的渲染阻塞 `<link>`，首帧即折叠）——但 dev 体验需修正。

## 修复（1 个文件）

把六条 `html[data-hero-collapsed]` 折叠镜像规则（height/banner/content/site-title/subtitle/waves/scroll-hint）从 `HomeHero.vue` 的 scoped 样式迁入全局 `src/main.css`：

- dev 下 main.css 经 Layout frontmatter 内联进 SSR HTML，首帧即折叠，与生产行为一致
- 规则改为普通选择器（`html[data-hero-collapsed] .home-hero …`），不再需要 `:global()`，也不受 .vue scoped 编译影响；作用域由 html 属性守卫
- `HomeHero.vue` 保留 collapsed class 的既有规则（水合后翻转用），两者计算值一致，无跳变

## 验证

1. dev 强刷首页（折叠态会话）：DCL 时刻首采样即 360 恒定，无波浪闪收
2. 生产产物（standalone）同样恒定 360；新访客（无标记）全屏 Hero + 滚动折叠动画不变
3. `npm run check` + `build` 全绿
4. AGENTS.md 记一条：影响首帧的关键样式放全局 main.css（.vue 岛样式在 dev 晚于首帧注入）
