修复抓图按钮点击报错（fetchingIds.has is not a function）

## 根因
AdminFriendLinkList.vue 中 fetchingIds = ref(new Set())：模板内引用自动解包，但 script 的 onFetchPreview 里漏写 .value，对 ref 对象调 .has() 抛 TypeError，API 请求未发出即崩溃。

## 改动（单文件 AdminFriendLinkList.vue）
1. onFetchPreview 内三处 fetchingIds → fetchingIds.value（has/add/delete）
2. 防并发静默失效：抓取进行中禁用所有行的抓图按钮（模板 :disabled="fetchingIds.size > 0"，自动解包），但仅抓取中的行显示"抓取中..."文案——修复 useAsyncAction 单实例 loading 守卫导致的"其他行点了没反应"，同时防连点重复提交

## 验证
- frontend/admin npm run build（vue-tsc）
- 手测：点击抓图仅该行进入抓取中、其余行按钮置灰但不显示文案；抓取完成后按钮恢复、toast 提示结果、列表刷新出头像/背景图
